# Ben 10 Omniverse Mod

Bring the Ben 10 Omniverse to Minecraft PE with realistic 3D models and abilities.

## Features

- Realistic 3D models and animations for 100+ aliens
- Abilities and interactions for each alien
- Omnitrix item for transforming into different aliens
- Entities for Ben 10, Heatblast, Four Arms, Upgrade, and Vilgax

## Requirements

- Minecraft PE 1.26.40
- Fabric Loader 0.15.11 or higher

## Installation

1. Download the mod from the releases page.
2. Place the mod file in the `mods` folder of your Minecraft PE game directory.
3. Launch Minecraft PE with Fabric Loader.

## Usage

- Obtain the Omnitrix item to transform into different aliens.
- Interact with the aliens to use their abilities.

## Configuration

No additional configuration is required. The mod is ready to use out of the box.
